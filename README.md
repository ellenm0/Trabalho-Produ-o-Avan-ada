# Sistema de Relatórios

Sistema desenvolvido em Python e Streamlit para geração de relatórios a partir das informações fornecidas pelo usuário.

## Como utilizar

1. Acesse o sistema pelo link disponibilizado.
2. Preencha as informações solicitadas.
3. Envie os arquivos necessários, quando solicitado.
4. Gere o relatório.
5. Faça o download do relatório gerado.

## Observação

Este sistema foi desenvolvido para facilitar a organização e a geração de relatórios de forma simples e padronizada.
